## AluraBooks - Uma Loja Online de Livros Técnicos

### Descrição
Este projeto, desenvolvido em HTML, CSS e JavaScript, simula uma loja online de livros técnicos, com foco em programação e desenvolvimento. A aplicação permite navegar por diferentes categorias de livros, visualizar detalhes de cada livro, adicionar itens ao carrinho e realizar uma simulação de compra.

### Tecnologias Utilizadas
* **HTML:** Estrutura básica da página, definindo os elementos como títulos, parágrafos, imagens e links.
* **CSS:** Estilização da página, definindo cores, fontes, layouts e responsividade.
* **JavaScript:** Interatividade da página, como o funcionamento do carrossel de livros e a manipulação do DOM.
* **Swiper:** Biblioteca JavaScript utilizada para criar o carrossel de livros.

### Estrutura do Projeto
O projeto está organizado da seguinte forma:

* **index.html:** Arquivo principal da página.
* **style.css:** Arquivo de estilos CSS.
* **reset.css:** Arquivo de reset de estilos para garantir consistência entre navegadores.
* **assets:** Pasta contendo imagens e outros arquivos de mídia.
